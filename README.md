# 🍔 버거 타워 대결 v6

기존 v5 기능을 유지하며 추가한 변경사항:

- 대기실에서 새 방 제목 지정, 방장이 대기 중/게임 종료 후 제목 변경 가능. 방 목록에도 제목 표시.
- **1~4인** 협동/대결 시작 가능. 협동 1인 플레이는 자신의 차례가 계속 이어집니다. 대결 1인 플레이는 패티가 바닥에 닿거나 제한시간이 종료되면 결과 화면이 나옵니다.
- 게임 종료 후 **모든 참여자에게 다시하기/나가기**가 표시됩니다. 다시하기는 방에서 나가지 않고 **같은 방 코드/참여 인원으로 즉시 새 게임을 시작**합니다. 2명 이상일 때는 한 사람이 누르면 전체 플레이어가 같이 새 게임을 시작합니다.
- **대결 모드에서 시간 제한을 설정한 경우** 우측 상단에 남은 시간이 `MM:SS` 형태로 표시됩니다. 무제한일 때는 숨깁니다.

## 실행

```bash
npm install
npm start
```

Render: Build `npm install`, Start `npm start`. 기존 저장소 파일 7개 교체 후 자동 배포.
