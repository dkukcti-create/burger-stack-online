# 🍔 버거 타워 대결 (최대 4인 온라인)

## 게임 규칙
- 한 방에 최대 4명 입장 가능
- 최소 2명만 모이면 **방장(👑)**이 **START**를 눌러 시작할 수 있습니다. 3명, 4명도 가능합니다.
- 입장 순서대로 번갈아 랜덤 재료를 배치하며, 물리 엔진은 서버에서 실행됩니다.
- 움직이는 재료의 좌표를 모든 플레이어에게 초당 30회 전송합니다. (네트워크 상태에 따라 약간의 지연 가능)
- 재료가 바닥으로 떨어지면 마지막 배치자가 패배합니다.
- 게임 시작 후 추가 인원 입장은 제한됩니다.
- 플레이 중 참가자가 나가면 게임은 대기 상태로 돌아가며, 남은 인원이 다시 START를 눌러 새 게임을 시작할 수 있습니다.

## Render 배포
기존 GitHub 저장소의 `server.js`, `package.json`, `public/index.html`, `public/game.js`, `public/style.css`, `README.md`를 새 파일로 덮어써서 커밋하세요. Render 자동 배포가 켜져 있으면 자동으로 배포됩니다. 설정은 Build: `npm install`, Start: `npm start`.

## 로컬 실행
`npm install` 후 `npm start` 실행, 브라우저에서 `http://localhost:3000` 접속.
