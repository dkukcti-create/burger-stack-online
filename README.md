# 버거 타워 대결 5.0

Node.js 20+ / Express / Socket.IO / Matter.js. Render Web Service에서 `npm install`, `npm start`로 실행합니다.

## 달라진 기능

- **협동**: 최대 네 명이 한 탑을 번갈아 쌓습니다. 재료가 하나라도 바닥에 닿으면 해당 턴에서 종료되고 쌓은 개수를 표시합니다. 중간 퇴장 시 남은 사람이 게임을 이어갑니다. 재료 충돌의 반발계수는 0이고 단단한 직사각형 물리 강체로 계산합니다.
- **대결**: 최대 네 명이 서로 다른 탑을 쌓으며, 재료는 미리보기부터 낙하까지 동일한 랜덤 재료로 표시됩니다. 30초/1분/2분/3분/5분/무제한 중 선택할 수 있습니다. 시간 종료 시 탈락 여부, 쌓은 재료 수를 기준으로 순위를 정합니다.
- **결과 화면**: 게임 종료 후 결과/승자/순위/쌓은 재료 수, 방장에게 '다시하기', 모두에게 '나가기'가 나타납니다.
- **대기실**: 연결된 서버 메모리에서 방 목록을 표시합니다. 게임 중이거나 인원 초과 상태인 방에는 입장할 수 없습니다.
- **사운드**: 외부 음원을 사용하지 않는 Web Audio 기반 배경음/효과음. '음악 켜기' 버튼을 누른 다음 재생됩니다. 브라우저의 자동 재생 제한을 준수합니다.

## 참고 및 제약

- 방은 **하나의 Node.js 서버 인스턴스 메모리**에 저장됩니다. 서버가 재시작되거나 여러 인스턴스로 확장하면 방이 유지/공유되지 않습니다.
- 접촉 안정성을 위해 반발 계수를 0으로 조정했지만 물리 엔진의 충돌 보정으로 인해 약간의 흔들림과 겹침 보정은 남을 수 있습니다. 재료를 축소하는 애니메이션 자체는 구현되어 있지 않습니다.
- 대결 모드에서 쓰러진 사람은 탈락하며 마지막 생존자 또는 제한시간 시점의 최상위 순위가 승자입니다. 쌓은 개수는 서버가 받아들인 낙하 횟수 기준입니다.
- 실제 여러 브라우저 간 네트워크 통합 테스트를 수행하지 않았다면 배포 이후 2~4개 기기에서 확인하세요.
