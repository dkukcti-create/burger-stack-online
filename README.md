# 🍔 버거 타워 대결 3.0

실시간 2~4명 온라인 햄버거 쌓기 게임입니다.

## 모드
- **협동 모드:** 하나의 햄버거를 번갈아 쌓습니다. 누군가 놓은 재료 때문에 탑이 무너지면 **그 재료를 놓은 플레이어가 즉시 패배**합니다. 상대가 마우스로 움직이는 재료의 미리보기도 전원에게 표시됩니다.
- **개인 대결 모드:** 각자 별도 탑에 **패티**를 동시에 쌓습니다. 각 참가자의 탑은 전체 참가자에게 2×2 화면으로 보이고, 패티가 무너지면 해당 플레이어가 탈락합니다. **마지막까지 살아남은 플레이어 승리**입니다.

## 시작하기
1. 최소 2명, 최대 4명이 같은 방에 접속합니다.
2. **방장**이 협동 또는 대결 모드를 선택합니다.
3. 방장이 `START`를 눌러 현재 인원으로 게임을 시작합니다.
4. 마우스를 움직여 위치를 정하고, 클릭하면 재료를 떨어뜨립니다. 대결 모드에서는 자신의 화면 구역 안에서만 조작 가능합니다.

## 로컬 실행
Node.js 20 이상 환경에서:
```bash
npm install
npm start
```
브라우저에서 http://localhost:3000 을 엽니다.

## Render 배포
기존 GitHub 저장소에서 `server.js`, `package.json`, `README.md`, `public/index.html`, `public/style.css`, `public/game.js`를 이번 버전 파일로 **교체**합니다. Render의 자동 배포가 켜져 있으면 기존 인터넷 주소를 그대로 사용합니다.
- Build: `npm install`
- Start: `npm start`
- 환경 변수 별도 설정 불필요

## 참고
방 상태는 서버 메모리에 저장되므로 재시작되면 사라집니다. 무료 Render가 잠들면 접속한 방도 종료될 수 있습니다. 서버 한 인스턴스를 전제로 동작합니다.
