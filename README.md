# 🍔 버거 타워 대결 — 실시간 2인용

각자 다른 컴퓨터에서 **같은 링크**로 접속해 한 번씩 번갈아 재료를 떨어뜨리는 온라인 게임입니다. 서버가 Matter.js로 물리 시뮬레이션을 계산하므로 두 화면에 같은 결과가 나옵니다.

## 로컬 실행

Node.js 20 이상을 설치하고 프로젝트 폴더에서:

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 엽니다. **localhost 링크는 다른 컴퓨터에서 접근할 수 없습니다.** 원격 플레이는 아래 배포가 필요합니다.

## 인터넷에 배포하기 (Render 예시)

1. 이 폴더의 파일 전체를 새 **GitHub 저장소**에 업로드합니다 (`public` 폴더 포함).
2. [Render](https://render.com/)에 로그인하고 **New → Web Service**를 선택합니다.
3. 해당 GitHub 저장소를 연결합니다.
4. **Language: Node**, **Build Command: `npm install`**, **Start Command: `npm start`**로 지정합니다.
5. 서비스를 배포하면 `https://(서비스명).onrender.com` 같은 공개 주소가 생성됩니다. 실제 주소는 Render에서 확인하세요.
6. 한 사람이 해당 주소에서 방을 만든 뒤 **초대 링크 복사**를 누르고 친구에게 보냅니다. 친구는 링크를 열고 **게임 시작 / 방 입장**을 누릅니다.

> 무료 인스턴스는 일정 시간 사용하지 않으면 잠들어 첫 접속이 늦어질 수 있습니다. 서버 1개 인스턴스 기준이며, 재배포/재시작하면 진행 중인 방은 사라집니다.

## 규칙

- 두 명이 모두 입장하면 시작합니다.
- 내 차례에 가로 위치를 마우스/터치로 선택한 뒤 눌러 재료를 떨어뜨립니다.
- 재료 종류는 랜덤으로 결정되며 서버에서 판정합니다.
- 재료가 탑에서 벗어나 바닥에 떨어지면 마지막으로 올린 사람이 패배합니다.
- 게임이 끝나면 **다시 대결하기**를 누를 수 있습니다.

## 구현 파일

- `server.js`: 방 관리, 플레이어 입장, 차례와 물리 판정
- `public/index.html`: 화면 구조
- `public/style.css`: 디자인
- `public/game.js`: 캔버스 드로잉, 포인터 조작, 실시간 동기화

## 참고

Render와 같은 단일 서버 플랫폼의 웹소켓 연결이 필요합니다. GitHub Pages만으로는 이 게임을 운영할 수 없습니다.
